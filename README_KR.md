# iToken Network (한글)

> **Language:** [English (영문)](README.md)

비트토렌트(BitTorrent) 스타일의 P2P AI 추론 배포와 컴퓨팅 파워 기반 주권형 암호화폐(iToken)의 결합.

iToken은 개인의 유휴 하드웨어(RTX GPU, Apple Silicon Mac Mini/Pro, CPU)를 실시간 디지털 자산으로 전환하는 탈중앙화 P2P AI 추론 네트워크입니다. 이미 로컬 PC에 설치되어 널리 사용 중인 로컬 LLM 엔진(LM Studio, Ollama, Kobold.cpp 등)과 플러그 앤 플레이 방식으로 연동하여, 사용자는 유휴 연산력을 제공하고 모델 품질과 생성 속도(TPS)에 비례한 **iToken**을 채굴할 수 있습니다.

---

## 🌟 주요 특징

1.  **범용 로컬 LLM API 연동 (Simple is Best)**
    *   복잡한 모델 가중치 배포나 GPU 연산 가속을 별도 구현할 필요가 없습니다.
    *   iToken 데몬은 표준 OpenAI 호환 로컬 API(`localhost:11434`, `localhost:1234` 등)에 다이렉트로 연결되는 가벼운 P2P 역프록시(Reverse Proxy) 게이트웨이 역할만 수행합니다.
    *   **제로 설정:** 구동 시 로컬 컴퓨터의 주요 포트를 자동 스캔하여 실행 중인 모델을 감지하고 DHT 네트워크에 노드 능력을 자동으로 게시합니다.
2.  **에너지 절약형 "1 Query = 1 Node" 라우팅**
    *   일상적 연산에서는 중복 계산을 완전히 배제합니다.
    *   노드의 담보(Stake)와 평판(Reputation) 점수를 바탕으로, 1개의 쿼리를 신뢰도가 입증된 1개의 노드에만 단독 라우팅하여 전체 네트워크의 전력 소모를 90% 이상 아낍니다.
3.  **낙관적 챌린저 분쟁 해결 (Optimistic Challenger Economics)**
    *   평상시 검증 연산 간접비(Overhead)를 0%로 유지합니다.
    *   사용자가 받은 답변의 품질 불량, 모델 위조, 비정상적 지연을 감지하면 소량의 iToken을 예치하고 이의(Challenge)를 제기합니다.
    *   이의 제기가 접수되었을 때만 검증 노드가 개입하여 수학적 검증(VeriLLM)을 돌리며, 사기가 적발된 노드의 담보 iToken을 몰수(Slashing)해 신고자에게 배분하고 시장에서 추방합니다.
4.  **속도(TPS) 및 하드웨어(CPU vs. GPU) 가치 차등**
    *   추론 보상은 토큰 생성 속도(TPS)를 반영해 실시간 보정됩니다.
        $$\text{보상} = \text{생성된 토큰 수} \times TQW_{M, Q} \times \text{Speed Multiplier}(TPS)$$
    *   고속 GPU 노드는 실시간 쿼리를 수주해 고단가 보상을 획득하고, 느린 CPU 노드는 속도가 무관한 저단가 비동기 배치 작업(예: 대용량 번역) 마켓에서 일감을 수주하도록 오더북 필터를 통해 효율 분배됩니다.
5.  **독립적 주권형 블록체인**
    *   Substrate Solo Chain 기반으로 빌드되어 비트코인, 이더리움 등 외부 암호화폐 시장 변동성으로부터 완전히 독립되어 생존할 수 있습니다.
